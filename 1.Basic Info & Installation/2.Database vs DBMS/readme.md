# Database vs DBMS

## What is a Database?

A **database** is a collection of organized data.
It stores information in a structured way so that it can be easily accessed, updated, and managed.

### Example of Database Data

| First Name | Last Name | City   | Contact  |
| ---------- | --------- | ------ | -------- |
| Paul       | Philips   | London | 39899829 |
| Raju       | Sharma    | Ranchi | 90890288 |
| Keto       | Leri      | Tokyo  | 50505005 |
| Sham       | Sha       | Delhi  | 602020   |

This table is a **database** because it stores information about people in an organized format.

---

## What is a DBMS?

A **DBMS (Database Management System)** is software that is used to create, manage, and control databases.

It acts as an **interface between the user and the database**.

With a DBMS, users can:

* Create databases
* Insert data
* Update data
* Delete data
* Search and retrieve information

### Examples of DBMS

* MySQL
* PostgreSQL
* Oracle
* Microsoft SQL Server
* MongoDB

---

## Database vs DBMS

| Database                      | DBMS                                 |
| ----------------------------- | ------------------------------------ |
| Collection of organized data  | Software used to manage the database |
| Stores the actual information | Provides tools to work with the data |
| Example: a table of users     | Example: MySQL, PostgreSQL           |

---

## Simple Analogy

Think of it like this:

* **Database → Library books**
* **DBMS → Librarian who manages the books**

The books store information, but the librarian helps you find, organize, and manage them.

---

## Simple Definition

**Database:** Organized collection of data.
**DBMS:** Software used to manage and interact with the database.
