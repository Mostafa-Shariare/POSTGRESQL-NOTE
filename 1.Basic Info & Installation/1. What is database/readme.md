# What is a Database?

A **database** is a structured way to store and organize data so that it can be easily accessed, managed, and updated.

Instead of keeping information in random places, a database stores data in an organized format, usually in **tables** with rows and columns.

---

## Example of Unorganized Data

Sometimes data exists in a messy form where information is separated and difficult to connect.

First Names
Paul
Raju
Keto
Sham

Last Names
Philips
Sharma
Leri
Sha

Cities
London
Ranchi
Tokyo
Delhi

Contacts
39899829
90890288
50505005
602020

In this case, the information is **not connected clearly**. It is hard to know which city or contact belongs to which person.

---

## Organized Data (Database Table)

A database organizes the same data into a **table structure**.

| First Name | Last Name | City   | Contact  |
| ---------- | --------- | ------ | -------- |
| Paul       | Philips   | London | 39899829 |
| Raju       | Sharma    | Ranchi | 90890288 |
| Keto       | Leri      | Tokyo  | 50505005 |
| Sham       | Sha       | Delhi  | 602020   |

Now each row represents **one person**, and each column represents **a type of information**.

---

## Why Databases Are Useful

Databases help to:

* Store large amounts of data
* Organize information clearly
* Search data quickly
* Update information easily
* Avoid duplication and confusion

---

## Simple Definition

A **database** is an organized collection of data stored in tables so that information can be easily stored, retrieved, and managed.
